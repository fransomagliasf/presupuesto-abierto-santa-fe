# Fuentes documentales

Esta carpeta conserva los PDF originales usados para construir y auditar los
datos del sitio. Se versionan en GitHub para que futuros cambios puedan partir
de las mismas fuentes sin volver a subir los documentos al chat.

Las fuentes históricas de finalidad y función que no fueron subidas en esta
sesión todavía no están disponibles como PDF en el repositorio. Sus datos
procesados y conciliados permanecen en `data/processed`.

Los PDF no se incluyen en el artefacto de GitHub Pages: permanecen accesibles
desde el repositorio, mientras la web pública carga únicamente los archivos
procesados necesarios.

`SHA256SUMS` registra la huella de cada documento para comprobar que una copia
local sea idéntica a la fuente versionada.
